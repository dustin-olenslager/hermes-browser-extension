What this can do

Hermes drives this browser's active tab: navigate, read the page, click, type, press keys, scroll, go back, list tabs, and take screenshots. It cannot run arbitrary JavaScript, read your cookies, or touch passwords. It will not act on browser-internal pages or local files, and "Limit to these sites" narrows it further — leave that blank to allow any normal web page. Disconnect at any time — the agent's browser tools then fall back to their configured backend.
